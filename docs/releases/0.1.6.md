# DSH Advisor 0.1.6

Unofficial project, independently developed and maintained by community members.

DSH Advisor lets the main model ask another model for focused advice. You review the complete request, edit or remove evidence, and approve each send. The advisor returns text; the main model continues to verify and execute the task.

## Included in this release

- Configure the advisor in Settings → Plugins → 顾问模型, using services already configured in DSH Models.
- Inherit the model service's token budget by default, with no additional plugin response-size cap. Existing custom caps can be disabled in Output settings.
- Review the exact destination and request before each send. Editing the request or changing configuration requires a fresh approval.
- Read a short result preview, expand the advice, and inspect the original text and request ID.
- Persist send markers and results to prevent automatic duplicate sends after interruption or restart.

## Install

Use **Node 24+**, **pnpm**, and **DSH 0.1.3-alpha.2**. This is the tested DSH version; compatibility with other versions has not been verified.

Download **dsh-tool-advisor.tgz** from this release, then run from the download directory:

```sh
dsh plugin --profile web add ./dsh-tool-advisor.tgz
dsh web
```

The `.tgz` contains the built plugin. The versioned `dsh-tool-advisor-0.1.6.tgz` attachment has identical contents. The README also provides a fixed latest-release download URL for installations without version numbers. GitHub's automatically generated source archives require a build before installation. If DSH is not installed yet:

```sh
npm install -g pnpm @deepseek-ai/dsh@0.1.3-alpha.2
```

In **Settings → Models**, configure the model service, including its saved Base URL, credentials, and model. In **Settings → Plugins → 顾问模型**, select the service and advisor model and save. The main task's model stays independently selectable. Plugin settings currently use Chinese labels.

## Verification and limits

51 automated tests pass, together with type checks, build checks, and actual DSH Loader tests for the built and unpacked module. Chromium checks cover settings persistence, restart recovery, custom limits, and concurrent editing. This release's tests use controlled adapters and local fixtures; earlier Flash → Pro → Flash cloud acceptance is documented separately in [ACCEPTANCE.md](https://github.com/kvmem/dsh-advisor/blob/main/ACCEPTANCE.md).

Verified on Linux with a local POSIX filesystem. Model capabilities, service budgets, and the default 120-second request timeout still apply. Each advisor call uses your configured model service and may incur its normal charges. No npm package has been published as part of this GitHub release.
