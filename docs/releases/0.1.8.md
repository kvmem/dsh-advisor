# DSH SuperAdvisor 0.1.8 — compatibility update

Prepared locally; not yet published.

Fixes selecting Code Mode sub-tool results as advisor evidence on DSH 0.1.5. Both the legacy and renamed result events are recognized, while per-call approval and duplicate-send protection remain intact.

DSH peer dependencies now explicitly support `0.1.2-alpha.4`, `0.1.2-alpha.5`, `0.1.2-rc.1`, `0.1.3-alpha.2`, and `0.1.5-alpha.1`. Node support is `^22.19.0 || >=24.2.0`; Node 24 is recommended. Reinstall DSH under the selected Node version when changing major versions, so its native dependencies are rebuilt, and retain your DSH_HOME, saved settings, and advisor audit directory.

Verified on Linux: 5 DSH releases × 4 Node versions, 53 tests per combination, real Loader checks, normal plugin installation, Chromium settings and restart checks, plus saved-result recovery across DSH versions without another send. Tests use controlled model responses and do not call paid models. See the [compatibility record](../COMPATIBILITY.md) for exact versions, unsupported releases, and repeatable checks.
