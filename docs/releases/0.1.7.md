# DSH SuperAdvisor 0.1.7

An on-demand second opinion for your main model, approved by you. This release renames **DSH Advisor** to **DSH SuperAdvisor**, with repository and package name `dsh-super-advisor`.

The main model still calls `ask_advisor`; you review, edit, approve, or reject each request. The advisor returns text advice for the main model to verify and use. Model services and credentials come from DSH Models. Output defaults continue to follow the model service, with no additional received-text size cap; service limits and the 120-second request timeout still apply.

## Typical setups

- **Local main model + cloud advisor:** use a tool-capable local model for routine work and approve focused consultations with a stronger cloud model when needed.
- **Flash main model + Pro advisor:** use Flash for execution and ask Pro for difficult questions or focused reviews. The aim is to approach stronger-model quality with lower usage and cost; no comparative quality or cost benchmark has been performed.

## Install

Requires Node 24+, pnpm, and DSH. Verified on Linux with a local POSIX filesystem and DSH `0.1.3-alpha.2`.

```sh
curl -fL https://github.com/kvmem/dsh-super-advisor/releases/latest/download/dsh-super-advisor.tgz -o dsh-super-advisor.tgz
dsh plugin --profile web add ./dsh-super-advisor.tgz
dsh web
```

In **Settings → Models**, configure the service, saved Base URL, credentials, and model. In **Settings → Plugins → DSH SuperAdvisor**, choose the advisor and save. Settings and result cards now show the SuperAdvisor name. The main model remains independently selectable; saving settings does not run inference.

## Upgrade from DSH Advisor

Finish or stop active tasks and exit DSH first. After downloading the new package, replace the old package in the same profile:

```sh
dsh plugin --profile web remove dsh-tool-advisor
dsh plugin --profile web add ./dsh-super-advisor.tgz
dsh web
```

Keep the same `DSH_HOME`, settings, audit directory, and any custom `storageDir`. The `advisor` settings namespace and patch row, `DSH_ADVISOR_*` initial-value variables, and `ask_advisor` tool are retained for compatibility. Keep one version installed per profile. See the [complete upgrade instructions](https://github.com/kvmem/dsh-super-advisor#upgrading-from-dsh-advisor-016-or-earlier).

The versioned `dsh-super-advisor-0.1.7.tgz` and fixed `dsh-super-advisor.tgz` assets are identical. The legacy `dsh-tool-advisor.tgz` asset preserves the original 0.1.6 bytes so old download commands do not silently change package identity. Use the new filename for 0.1.7. SHA256SUMS covers all three assets. Existing 0.1.6 release assets and Git history remain intact.
